System overview

Every request from this page goes through the API gateway on :8080, which finds each service through Eureka.

Service status

How a request flows

Browser (this page)
→ every call goes to the gateway only
api-gateway :8080
→ checks the login JWT, then routes lb://<service>
eureka-server :8761
→ tells the gateway (and order-service) where each service lives
user-service :8081
/api/users/**
register, login, issue JWT
product-service :8082
/api/products/**
catalog, admin CRUD, download tokens
order-service :8083
/api/orders/**
purchase, history; calls product-service via Feign

Try it

  1. Account: register a user. You get a login JWT, decoded on that tab.
  2. Admin: add products (needs an ADMIN account; instructions are on that tab).
  3. Catalog: buy a product. order-service records the order and gets a 5-minute download token from product-service.
  4. My orders: download it, inspect the download token, or request a fresh one after it expires.

The panel on the right logs every API call and which service handled it.
